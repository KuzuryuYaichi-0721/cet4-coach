# 使用说明（写给第一次用的你）

## 0. 先准备三样东西

1. **Windows 10/11 电脑**。不用装 Python、Node.js。Windows 自带的 PowerShell 或 PowerShell 7 都可以。
2. **DeepSeek API Key**（可选，但没有它就没有 AI 讲解/评估）。在 PowerShell 里运行：

   ```powershell
   setx DEEPSEEK_API_KEY "你的Key"
   ```

   然后关掉 PowerShell，重新打开。Key 只存在环境变量里，程序不会把它写进 `config.json` 或日志。
3. **听力素材**（可选）。先放到：

   ```text
   CET4Coach\library\source_audio\
   ```

   已按 Section 分好的文件最好；整卷也行，但要先在 `data\audio_timepoints.json` 补该套卷各 Section 的起止秒。

## 1. 第一次打开

双击 `RUN.bat`。先出现 5—8 分钟入门微课：

- 一张卷分值表；
- 听力每题分值柱状图；
- 阅读三种题型性价比和做题顺序；
- 写作/翻译稳分位置；
- 整场时间轴。

最后 3 道题全对才进主菜单。答错不会扣分，会带你回对应那一页再讲一遍。

## 2. 单词 30 分钟

- 每天约 26 个新词：13 个核心词（英译中 + 中译英 + 造句）+ 13 个认识词（只英译中），再加昨天没掌握的错词。
- 先看英文句子猜中文意思；点“提交给老师”后看释义和反馈。
- 核心词会继续让你写英文、造短句。拼写小错不扣分；造句只要求体现词义。
- 左上角倒计时 30:00。到点立刻停止出新词，没完成的进明天复习。
- 结束时自动清掉临时听力，并告诉你“已删除临时文件 N 个，源音频目录未变动”。
- 中途点“保存并退出”，下次从同一词、同一步继续。

## 3. 20 题 30 分钟

- 每轮至少 12 题来自仔细阅读/听力篇章；至少 6 题同一种主攻题型；2—3 种题型混合。
- 先选答案，再用一句话说理由。大模型会看你的理由质量；答错会按固定结构讲解。
- 听力题先点“播放听力”，再点“我已听完，显示选项”。播放次数会记录，供评估参考。
- 阅读题超过 3 分钟、听力超过 2 分钟会轻提醒：先选一个，后面看讲解。
- 30 分钟到点自动结束。未答的题不算正确率，但会进待复习队列。
- 完成 20 题才额外记“刷题打卡”；单词 30 分钟是基础打卡。

## 4. 打卡与周复盘

- 左侧“打卡月历”：绿色是完成基础打卡，带“刷”是当天还做了 20 题。
- 连续 7/14/30 天会显示一句简短鼓励，不重复刷屏。
- 每周日首页会自动生成一次“本周错题画像”：错得最多的 2 个题型 + 1 个共同错误模式 + 1 个下周动作。也可在打卡页手动生成；会缓存，不会重复花钱。

## 5. 整理听力

1. 把原始素材放进 `library\source_audio\`。
2. 打开“听力整理”，先看 ffmpeg 是否可用。
3. 点“开始整理”：
   - 已分 Section：直接复制重命名成 `library\audio\<套卷>\SectionA.mp3`，不转码；
   - 整卷：只有 `data\audio_timepoints.json` 有明确起止秒才切；没有就跳过并写缺失报告，不会猜。
4. 整理完看“缺失报告”，补素材或补时间点后再整理。

时间点示例（秒）：

```json
{
  "2023-06-set1": {
    "SectionA": [0, 420],
    "SectionB": [420, 900],
    "SectionC": [900, 1500]
  }
}
```

## 6. 导入题库

- 支持 cet-practice 的真实 SQLite（`seed/cet6.db`）或同字段 JSON。
- 导入按题干+选项哈希去重；会备份旧 `questions.json` 到 `data\backup\`。
- 导入后看“缺口报告”：2020—2025 唯一题量 1,668，重点题 620，低于 1,080 个重点题位；系统会 7 天后重出旧题，不伪造新题。想补更多新题，请人工确认后导入 2015—2019 或 2026 的结构化数据。

## 7. 设置与诊断

- 只显示有没有 Key，不显示 Key 内容。
- 可以测试连接、打开 data 文件夹、重看微课。
- 如果 ffmpeg 显示未找到：把 ffmpeg 的 `bin` 目录加入 PATH，或把 `config.json` 的 `listening.ffmpeg` 改成完整 `ffmpeg.exe` 路径；`ffprobe` 同理。
- 如果 PotPlayer 未找到：在 `config.json` 的 `listening.potPlayer` 填 `PotPlayerMini64.exe` 的完整路径。

## 8. 常见问题

**Q：为什么我每天没到 26 个新词就到 30 分钟了？**  
很正常。单词模块的设计就是 30 分钟硬边界，没完成的词会进入次日待复习队列；它不要求你在 30 分钟内硬塞完。

**Q：为什么有时不调用大模型？**  
本地能明确判断“中文释义对上了”时，会直接给反馈以省钱；只有模糊、造句、刷题理由质量等需要模型判断。没 Key 或当天预算用完时，会自动降级本地判断，不中断学习。

**Q：为什么题库不到 1800 题？**  
2020—2025 的真实数据按题干+选项去重后只有 1,668 道唯一客观题，重点题 620。系统用 7 天后重出补齐题位，并如实写缺口报告；没有伪造题目。

**Q：听力原文会不会提前显示？**  
不会。听力题只显示题干/选项（听完后显示选项），原文只在讲解里作为参考。

**Q：临时文件在哪？**  
`%TEMP%\CET4Coach\listening_<日期>\`。每次单词/刷题结束会删除；超过 1 天的残留会在启动时清理。源音频和题库不动。

**Q：能离线用吗？**  
题库、单词、复习、打卡、听力整理都可离线。只有回答评估、错题讲解、周画像、趣味句预生成需要 DeepSeek；没有 Key 时会用本地规则降级。

**Q：数据在哪里备份？**  
整个 `data` 文件夹就是学习记录；直接复制走即可。`data\logs\llm.jsonl` 不含 Key，也不含完整题干。
