This folder is for the learner's own source audio files.
The app never deletes files here.

Put already-split files (preferred) or whole-paper MP3/M4A/WAV here, then use
the Listening page in the app.

Accepted naming examples:
  2023.06_set1.mp3
  2023年6月第1套.mp3
  2023_06_set1_sectionA.mp3
  cet4-2021-06-set-01.mp3

Whole-paper files need explicit start/end seconds in data/audio_timepoints.json.
The app will not guess timepoints.
